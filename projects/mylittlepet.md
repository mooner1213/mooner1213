# 🐾 MyLittlePet

[← 플레이룸으로 돌아가기](../README.md)

**가상 강아지를 쓰다듬고 공놀이하며 함께 지내는 Unity 기반 VR/MR 팀 프로젝트입니다.**

행동과 상호작용을 먼저 구현하고 시험하는 프로토타입을 제작했습니다. 공통 플레이 로직에 PC Editor와 Quest 2 VR·Quest 3 MR의 실행 환경을 연결하는 구성입니다.

| 기능 | 내용 |
| --- | --- |
| 행동과 시선 | 자율 배회·사용자 추적·장애물 회피와 애니메이션·시선 전환 |
| 쓰다듬기 | 접촉과 손의 움직임을 이용한 판정 및 반응 |
| 공놀이 | 공 잡기·던지기·추격·물기·반환과 실패 상황 복구 |
| 강아지 들기 | 잡기와 내려놓기·자세 보정·머리와 꼬리 움직임 |
| 돌봄과 도입 | 허기·피로에 따른 식사·수면 행동과 입양·이름 입력 흐름 |

참여 범위는 강아지 행동·상호작용 프로토타입과 PC·XR 기능 시험입니다. Quest 환경 기능 시험과 모서리·장애물·바닥 이탈 상황의 복구 시험을 수행했습니다. 이 소개는 해당 프로토타입 범위를 설명하며 팀 통합본의 최종 반영 범위와 기기별 성능 검증은 별도로 관리합니다.

개발 원본은 외부 에셋의 이용 조건에 맞춰 비공개로 관리합니다. 이 소개 문서에는 구매한 모델·텍스처·애니메이션·프리팹 원본을 포함하지 않습니다.
