# ⏸️ 일시정지! · GamePaused

[← 플레이룸으로 돌아가기](../README.md)

**시간을 멈추고 점프를 설계하며 성벽을 오르는 2D 도트 등반 플랫포머입니다.**

[프로젝트 소개와 코드](https://github.com/mooner1213/-GamePaused-) · [게임 기획서 PDF](https://github.com/mooner1213/-GamePaused-/blob/main/Docs/Planning/GamePaused_게임기획서.pdf) · [기획 요약](https://github.com/mooner1213/-GamePaused-/blob/main/Docs/Planning/README.md)

- 지형을 관찰한 뒤 ESC로 정지하고 Space를 누르는 시간으로 점프를 예약합니다.
- 정지를 해제해 점프를 실행하고 벽 반사와 착지 결과를 다음 경로 계획에 활용합니다.
- ESC의 배신을 전·후반의 규칙 변화로 연결하는 스토리를 기획했습니다.

| 팀원 | 담당 |
| --- | --- |
| 문재혁 | 기획·스토리·플레이 흐름·UI 콘셉트 디자인 |
| 전주호 | Unity 개발·게임 기능 구현·애니메이션 |

현재 프로토타입에는 점프 입력 기록·벽 반사·예상 궤도·발판과 기믹·카메라·HUD 코드가 포함되어 있습니다. 후반부와 보스전·업적 등은 후속 설계·제작 범위이며 전체 스토리 구현과 완주 검증은 진행 중입니다.
